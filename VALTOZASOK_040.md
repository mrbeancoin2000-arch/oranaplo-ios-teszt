# ÓraNapló 0.4.0

Új: StoreKit 2 automatikusan megújuló éves Pro-előfizetés (termékazonosító készen; tényleges vásárlás App Store Connect nélkül nem elérhető), ellenőrzött jogosultság, ingyenes pulzus-fiók.

Új: felhasználó által választható 100%-ban központosított felületi fordítás HU/EN/DE, natív iOS adatkezelési hozzájárulásfordításokkal; 3 lépéses onboarding.

Új: legutóbbi edzés valódi HealthKit-adatok alapján, Apple Health eredetű magas/alacsony pulzus események, óvatos egyéni lépésszám-összevetés.

Javítás: 30 nap/1 év/5 év előzményimport külön könyvjelzővel fiókonként és időablakonként; lejárt Pro után függő prémium rekordok fel nem töltése.

Javítás: GPS-kimaradás nem számít folyamatos 100 méteres szakasznak.

Megmaradt: Google Sheets létrehozás/megnyitás, offline queue, napló (Pro), külön lapok, Windows BAT, GitHub Actions macOS build, részletes logok.

**Ismert korlátok:** HealthKit-aláírás, StoreKit éles termék, végleges iOS-build és régi Sheets duplikációk törlés/reinstall után tesztelendők. Eladásra nem kész.
